 HelpingHands – Volunteer & Donation Coordination Portal

 About the Project

HelpingHands is a web-based platform that connects NGOs, volunteers, and donors in one place. It simplifies volunteer management, social activity coordination, and donation tracking.

 Key Features

- User Registration and Login
- Role-Based Access (Admin, NGO, Volunteer, Donor)
- Volunteer and NGO Dashboards
- Create and Browse Activities
- Volunteer Join Requests
- Approve or Reject Requests
- Donation Submission and Tracking
- Admin Management

 Project Structure

The project contains frontend pages, JavaScript files, Flask backend APIs, database logic, and an SQLite database.

 Git Workflow

We follow a feature-branch workflow. Each team member works on a separate feature branch and submits Pull Requests to `develop` for integration.

 Project Goal

To make volunteering and donation coordination easier through a centralized and user-friendly platform.
